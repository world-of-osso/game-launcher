# Game Launcher

Dioxus desktop app that downloads and launches game files listed in `https://files.worldofosso.com/manifest.json` (public R2 bucket `worldofosso-client`).

## Related Projects

- Publisher: `../game-engine/deploy.sh` uploads bundle + manifest to R2 (manifest generated by `../file-server`)

## Architecture

- `src/main.rs` — single-file app: UI components, manifest fetch, file sync, self-update
- `assets/style.css` — Battle.net-style dark UI
- Manifest is cached locally (`.manifest_cache.json`) with ETag/Last-Modified conditional requests

## Build

```bash
cargo run          # dev
cargo build --release
```
